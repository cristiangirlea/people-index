# Security policy

## Supported versions

Security fixes are supported for the latest release and the `main` branch.

## Reporting a vulnerability

Please report vulnerabilities privately using [GitHub private vulnerability reporting](https://github.com/cristiangirlea/people-index/security/advisories/new). Do not open a public issue for a vulnerability.

In the private report, include a description of the problem, affected versions, steps to reproduce, potential impact, and any relevant logs or proof of concept. Remove secrets and personal data from the report.

If the link above offers no report form, private reporting is not available yet. Then open a public issue titled "Security contact request" that contains nothing about the vulnerability (no description, component or version), and a maintainer will reply with a private way to send the report.

The maintainers will review the report, may ask for more information, and will use the private report to discuss a fix and disclosure. Response and fix times depend on the report.
